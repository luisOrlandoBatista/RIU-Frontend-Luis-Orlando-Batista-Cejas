# RIU Frontend

Aplicación en Angular 19 para gestionar un catálogo de superhéroes. CRUD completo con búsqueda y paginación.

## Stack

- Angular 19 + Angular Material 19
- Tailwind CSS v4
- Karma / Jasmine

## Arrancar

```
npm start
```

## Tests

```
npm run test:ci
npm run test:coverage
```
